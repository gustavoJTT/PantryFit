> System for meal management, nutritional tracking, and pantry inventory management.

PantryFit is a system designed to integrate pantry inventory management with meal tracking and nutritional analysis.

## Project purpose

The project connects the food available at home with what is consumed during the day. It is intended to support food registration, stock control, meal records, and nutritional monitoring in a single system.

PantryFit is also an academic and portfolio project focused on software engineering, Java, Spring Boot, PostgreSQL, layered architecture, Docker, and automated testing.

## Main features

- Food registration and categorization;
- Pantry stock control;
- Inventory entry, withdrawal, and adjustment records;
- Meal registration with ingredients and quantities;
- Calorie and macronutrient calculation;
- Automatic stock updates based on consumption;
- Historical records for meals and inventory movements.

## Technology stack

- Java 21+
- Spring Boot 4.1.1
- Maven
- PostgreSQL
- Docker and Docker Compose

## Getting started

Requirements:

- Java 21 or later;
- Maven or the Maven Wrapper;
- Docker and Docker Compose.

Run the application locally with:

```bash
./mvnw spring-boot:run
```
